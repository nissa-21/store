Conexión Directa con GitHub (1 Clic)

Permite publicar cambios sin salir del navegador y sin tocar código
1 Andá a tu cuenta de GitHub > Settings > Developer Settings > Personal Access Tokens > Tokens (classic).
2 Creá un token con permiso repo (o Contents: Read & write). Es 100% gratuito.
3 Pegá el token y datos abajo. Se guardan únicamente en tu navegador y nunca son públicos.
Tu token queda protegido en el almacenamiento local de este navegador.
